# 鲨鱼与鱼群碰撞升级需求

本轮按用户确认的方案实施：新增一条黑鳍礁鲨，将图鉴扩展到 12 种；独立体形、鳃裂、背鳍、胸鳍、不对称尾鳍，身体尾部联动，外围巡游，按体型调整跟随镜头。

解决真实鱼体穿透，保留正常的前后遮挡：预测避让、空间分区邻域查询、按体形设置分段碰撞体、有限迭代纠正、再次检查环境边界；出生和提高密度先找安全空间，拥挤时暂缓新增。

鲨鱼经过时小鱼按距离和种类延迟避让，并逐渐恢复；本轮不增加捕食死亡。食物分散、目标分配、接近减速、吃后离开，保持冷却和数量上限，鲨鱼不吃普通饲料。

补充胸鳍和转弯动画；图鉴采用当前选中物种的真实三维模型预览；低画质保留基础防穿透。验收覆盖连续投喂、密度和画质切换、鲨鱼边界巡游、惊扰恢复、暂停和后台恢复。严格区分自动测试、浏览器操作、真机 FPS。
