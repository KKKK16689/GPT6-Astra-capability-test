# 用户升级要求追踪

目标：保留 Three.js 实时交互海洋，提升鱼类多样性、水体、双端体验、性能和工程结构。

1. 10—12种可辨识鱼：本版11种，外形/花纹/速度/行为区分。
2. 群游、礁鱼、底栖与昼夜：已实现近似行为。
3. 避障、受惊延迟、恢复、限流投喂：已实现；精细视觉验收待真机。
4. 图鉴、独立点选、信息、跟随退出、密度：已实现；图鉴使用示意图。
5. 果冻面/边/侧壁联动及船体浮力：保留并增加侧壁弯曲。
6. 手机抽屉、横竖屏/安全区、双指取消与桌面操作：保留，新增模式菜单和图鉴适配。
7. 多维画质：已实现；网格精度刷新生效。
8. 展开源码、测试、构建和部署：交付并验证流水线结果。
9. 自动测试/浏览器/真机严格区分：见 VALIDATION.md。
10. 原始完整需求以本对话用户《Jelly Ocean升级需求说明》为准。未验收项目不能标记完成。
