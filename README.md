# GPT6-Astra能力测试 · Jelly Ocean v3

[在线体验](https://kkkk16689.github.io/GPT6-Astra-capability-test/)

自包含 Three.js/WebGL 2 果冻海洋，直接打开 `index.html` 即可离线运行。

## 本次升级
- 11 种风格化礁鱼：小丑鱼、蓝绿雀鲷、蝴蝶鱼、皇帝神仙鱼、蓝倒吊、黄倒吊、六线隆头鱼、拟花鮨、银汉鱼、虾虎鱼、鳚鱼。体形、鳍形、花纹及速度存在区别，并非仅换色。
- 群游、礁区巡游、底栖停留；水面扰动引发有延迟和距离衰减的避让；昼夜影响活跃度。
- 独立观察/投喂模式，图鉴、鱼类信息、跟随与退出；投喂间隔两秒，最多 18 颗食物，自动过期或被吃掉。
- 画质联动鱼群上限、行为计算频率、阴影、草和气泡数量、反射与焦散更新频率。水面网格精度在刷新后按档位初始化，避免切换时重置物理。
- 水体侧壁增加与波面联动的弯曲，保留连续边缘和小船浮力。

## 操作

左侧/手机上方模式菜单选择触摸海洋、自由观察、观察生物或投喂。图鉴也可直接选择某种鱼。鱼类卡片提供跟随、退出和关闭；Esc 退出。双指缩放/平移不执行点选或投喂。暂停时停止生态与物理更新。

## 开发

```sh
npm ci
npm test
npm run build
```

源码直接位于 `src/`，测试位于 `tests/`，报告在 `docs/`。`dist/index.html` 为构建成品。GitHub Actions 检查测试、构建一致性，成功后自动更新 `main` 的单文件成品，Pages 从 main 根目录发布。

## 范围与限制

真实 3D 几何、弹性高度场和程序化生态近似；不是完整三维流体或生物学模拟。图鉴为示意图，不是物种鉴定图谱。避障使用保守代理体积，仍需视觉排查珊瑚细枝穿插。鱼胸鳍为静态几何，尾鳍随速度摆动。

自动测试通过不等于浏览器或真机验收。当前云浏览器无法创建 WebGL 上下文；手机/电脑帧率、视觉及端到端操作待真机验证，详见 docs/VALIDATION.md。
