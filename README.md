# GPT6-Astra能力测试 · Jelly Ocean v4 · 与鲨同行

[在线体验](https://kkkk16689.github.io/GPT6-Astra-capability-test/)

自包含 Three.js r170 / WebGL 2 果冻海洋。下载根目录 `index.html` 可直接离线打开；完整源码在 `src/`，也提供 `GPT6-Astra-capability-test.zip`。

## 本次升级

- 12 种鱼：小丑鱼、蓝绿雀鲷、蝴蝶鱼、皇帝神仙鱼、蓝倒吊、黄倒吊、六线隆头鱼、拟花鮨、银汉鱼、虾虎鱼、鳚鱼，以及 **1 条黑鳍礁鲨**。
- 鲨鱼有独立的流线身体、鳃裂、黑色背鳍尖与不对称尾鳍，后半身连续弯曲，外围巡游。小鱼有延迟、距离衰减的避让和恢复；鲨鱼不吃普通饲料。
- 朝向相关的多球体鱼身碰撞、空间分区查询、预测避让、迭代穿透纠正；修正后再次检查海底、礁石、码头桩和水体边界。无法获得安全位置时暂缓添加小鱼。
- 投喂不再覆盖避让力。食物散落，每颗分配一条鱼，靠近时减速，吃后离开；投喂间隔两秒、最多 18 颗、12 秒过期。
- 胸鳍独立运动、转弯倾斜；图鉴使用与海洋相同的真实三维几何，每次仅预览一种鱼，关闭时停止循环并释放模型。
- 碰撞和运动固定 60 Hz；行为决策随档位为 15 / 25 / 40 Hz。默认 44 条小鱼 + 1 条鲨鱼，上限 88 + 1；手机和节能档有更低上限。

## 操作

模式菜单：触摸海洋 / 自由观察 / 观察生物 / 投喂。打开“鱼类图鉴”，默认预览黑鳍礁鲨；点击“在海洋中观察”进入跟随，鱼卡提供退出跟随和关闭，Esc 也可退出。鲨鱼跟随镜头按体型和屏幕比例拉远。

鼠标拖动旋转、滚轮缩放、右键或 Shift 拖动平移；手机双指缩放和平移。水面模式单指揉水，观察/投喂模式轻点执行，拖动旋转。暂停停止生态与水体；切换后台清除水面拖拽。

## 开发与部署

```sh
npm ci
npm test
npm run build
```

`dist/index.html` 是构建成品。GitHub Actions 对推送和 PR 执行测试与构建；仅 main 成功后使用 Pages artifact 部署 `dist/`。工作流不自动提交根目录成品；发布时同步根目录 HTML 与源码 ZIP。

## 技术近似与验证限制

鱼身接触是保守多球代理，并非逐三角形碰撞；柔软鳍尖、尾尖和细珊瑚枝仍可能视觉穿插。二维画面上的前后遮挡是正常现象。生态是可解释的近似，不模拟捕食死亡或完整生物学；水体使用弹性高度场，不是完整三维流体。

水面网格切换需刷新。图鉴展示真实模型，但不是物种鉴定图谱。当前云端 Chrome 无法创建 WebGL 上下文，实际画面、触摸手势、手机/电脑 FPS 尚未实测；不宣称全部验收通过。数值测试、设备信息及剩余检查见 `docs/VALIDATION-v4.md`，上一版记录保留。
