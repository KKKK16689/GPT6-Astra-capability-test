# GPT6-Astra能力测试

## Jelly Ocean · 交互式果冻海洋

[点击在线体验](https://kkkk16689.github.io/GPT6-Astra-capability-test/)

Three.js + WebGL 2 实时 3D 海洋，内置全部资源。也可下载根目录 `index.html`，无需联网即可打开。

- 手机：底部触控工具、参数抽屉、更多菜单、横竖屏和安全区适配；单指触摸或拖拽，双指缩放平移。
- 电脑：可收起侧栏、鼠标旋转/缩放/平移、全屏和键盘快捷键。
- 沉浸模式、自动/节能/高清画质、参数记忆。自动画质支持负载降低后恢复清晰度。
- 水面为固定步长弹性高度场，带惯性、阻尼和张力；小船采样实际波面浮动。折射、反射与焦散采用实时近似。

## 完整源码

下载仓库中的 **GPT6-Astra-capability-test.zip** 并解压。压缩包包含 `src/`、`tests/`、构建脚本、锁定依赖和 CI 配置。源码目录位于此压缩包内。

解压后运行：

```sh
npm ci
npm test
npm run build
```

构建产物为 `dist/index.html`，替换仓库根目录的 `index.html` 即可更新 Pages。

物理、船体、几何、触摸判定与画质调节自动测试已通过。当前测试浏览器禁用 WebGL，真机视觉、触摸手感和帧率尚未验证。
